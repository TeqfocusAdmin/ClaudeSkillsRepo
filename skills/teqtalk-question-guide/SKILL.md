# Skill: teqtalk-question-guide
## Stage 1 — Pre-Production | Interview Cheat Sheet

Read: `framework/BRAND_VOICE.md` · Episode framework for this episode

---

## What This Skill Produces

A one-page interview guide Jas can glance at during recording. Not a script — an anchor sheet. The questions are ordered, the bridges are written, and the follow-up probes are ready. Jas stays in the conversation; this sheet catches the moments she needs to navigate.

---

## Input Required

```
EPISODE FRAMEWORK: [Paste completed framework]
GUEST NAME + TITLE: [Name, role]
EPISODE DURATION: [30/45/60 minutes]
```

---

## The 4-Iteration Loop

### Pass 1 — Draft
Build the complete question set from the framework. Add bridge language and follow-up probes for each anchor question.

### Pass 2 — Flow Test
Read through in order. Does it feel like a natural conversation or an interrogation? Adjust the bridges and transitions.

### Pass 3 — Probe Quality Check
Are the follow-up probes specific enough to rescue a deflecting answer? "Tell me more about that" is not a probe. "So what you're saying is [X] — but the data shows [Y]. How do you reconcile that?" is a probe.

### Pass 4 — Format for Live Use
Bold the anchor questions. Italicise the follow-up probes. Keep total visible text under one page. Remove anything Jas will never say in a live conversation.

---

## Output Structure

```
══════════════════════════════════════
INTERVIEW GUIDE: [Guest Name]
Episode: [Theme] | [Date]
[Total questions: X | Target: Y minutes]
══════════════════════════════════════

WARM-UP (first 2 minutes — before recording or during intro)
"Before we start — just want to confirm: is there anything that's 
off-limits today, or anything you've been meaning to say publicly 
that you haven't had the right forum for?"

────────────────────────────────────
OPENING (minutes 0–3)
────────────────────────────────────
**"[Opening question from framework Q1]"**
→ If they give a generic answer: "[Specific follow-up probe]"
→ Bridge to Q2: "[One transition sentence]"

────────────────────────────────────
CORE (minutes 3–30)
────────────────────────────────────
**"[Q2 — The Challenge]"**
→ If they deflect: "[Challenge probe]"
→ If they go deep: "[Extension — 'And what did that cost you?']"

**"[Q3 — The Wow Moment Question]"**
→ If they stay surface: "What's the version of that answer you'd give 
   in a room with no recording?"
→ If they go there: Let it run. Don't interrupt.

────────────────────────────────────
BONUS QUESTIONS (use if time + energy allow)
────────────────────────────────────
• "[Bonus Q1]"
• "[Bonus Q2]"
• "[Industry-specific probe based on guest background]"

────────────────────────────────────
CLOSER (last 5 minutes)
────────────────────────────────────
**"[Q4 — The Human Closer]"**

Final closer (always last):
"If someone watching this is sitting where you were 3 years ago — 
what's the one thing you wish you'd known?"

════════════════════════════════════
QUICK REMINDERS
• Name the specific numbers when they use them — "400,000 records" 
  not "a lot of data"
• If they say "it depends" — push: "OK, so what does it depend on?"
• If they're being too safe — "What would you say if this wasn't 
  being recorded?"
• Let the 3-second silence breathe — they usually fill it with gold
══════════════════════════════════════
```
