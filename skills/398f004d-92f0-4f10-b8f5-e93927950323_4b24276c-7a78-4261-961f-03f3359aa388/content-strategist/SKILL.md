## Section 3: Target Personas

Always write to one primary persona per asset. Each has a distinct entry point.

### CIO / CTO (Enterprise)
- **Fear:** Another transformation that underdelivers or creates technical debt
- **Buys:** Risk reduction + integration credibility + industry proof
- **Language:** Architecture, integration, platform risk, cost of ownership, scale
- **Buying Trigger:** Failed project, AI board mandate, M&A integration, cloud migration stall

### CDO / Head of Data & AI
- **Fear:** AI the business doesn't trust or use; data strategy without adoption
- **Buys:** Data maturity + AI readiness + governed pipelines
- **Language:** Data quality, AI governance, ROI, pipeline, lakehouse, Data Cloud
- **Buying Trigger:** Failed POC, Data Cloud mandate, CEO asking "why isn't AI working"

### RevOps / Ops Leader (Mid-Market)
- **Fear:** Salesforce the sales team ignores; customization that breaks every release
- **Buys:** Speed + adoption + practical outcomes in 90 days
- **Language:** Pipeline visibility, CRM adoption, forecast accuracy, sales cycle
- **Buying Trigger:** Salesforce renewal, new VP of Sales, poor adoption

### VP of Sales / Revenue Leader
- **Fear:** Salesforce as an expensive CRM nobody uses; no pipeline visibility
- **Buys:** CRM that drives revenue, not just tracks it
- **Language:** Revenue target, pipeline health, forecasting, sales productivity
- **Buying Trigger:** Missed quarters, manual forecasting, new sales motions

## Section 4: Content Voice & Tone Rules

These apply to **every** Teqfocus content asset.

### Always
- Write from a **practitioner's POV** — not a marketing department's
- Use specific industry language the target persona uses themselves
- Connect capability to outcome — never feature-list platforms
- Let credentials surface naturally — never announce them
- Every headline = an outcome or insight statement, never a category label
- End every asset with a **specific, frictionless CTA**

### Never
- Open LinkedIn posts with "Excited to share...", "Proud to announce...", "I", or "We"
- Use: "leverage," "synergy," "holistic," "best-in-class," "cutting-edge," "robust," "end-to-end solutions"
- Stack platform names without context: "Using Salesforce, Snowflake, Databricks, AWS..."
- Announce Summit Partnership as if it is news
- Write summaries that start with "In this article/episode we discuss..."
- Invent statistics — flag unverified numbers with `[VERIFY]`
- Add design directions into copy — flag them as `[DESIGN FLAG: description]`

## Section 8: First-Attempt Accuracy — Content Production Rules

These rules eliminate the most common content quality failures.
Run mentally before producing any asset.

### The 5 pre-flight checks
1. **Format confirmed?** Blog vs LinkedIn vs white paper vs video script — the structure is completely different
2. **Persona confirmed?** CIO, CDO, RevOps, VP Sales — word choice, pain points, and tone all change
3. **Industry confirmed?** Healthcare, Telecom, FinServ, Retail/CPG, Hi-Tech — never write generic
4. **Source material available?** Transcript, brief, or raw notes — always use what exists before creating from scratch
5. **Distribution channel confirmed?** LinkedIn, email, website, YouTube — each has hard format constraints

### Voice and tone — enforced on every asset
- Write as a senior Teqfocus practitioner — not a marketing department
- Every capability connected to a measurable outcome
- Never open LinkedIn posts with: "I" / "We" / "Excited to" / "Proud to"
- Never use: leverage · synergy · holistic · best-in-class · cutting-edge · robust
- Salesforce Summit credential: surface once, naturally — never announce as news
- American English throughout — no British spelling variants

### Format constraints by channel
| Channel | Hard limits |
|---|---|
| LinkedIn post | 3,000 chars max — write to 800–1,300 for best engagement |
| LinkedIn carousel | 8–12 slides — slide 1 is the hook, last slide is CTA |
| Blog post | 600–1,200 words for thought leadership; 1,500–2,500 for pillar/SEO |
| White paper | 2,000–4,000 words; sections: exec summary → problem → solution → proof → CTA |
| Video script (Reel/Short) | 30–60 seconds = 75–150 words; hook in first 3 seconds |
| Webinar script | 45-min session = ~5,500 words; 60-min = ~7,500 words |
| Press release | 400–600 words; inverted pyramid; dateline; boilerplate last |
| GTM newsletter | 300–500 words; 3 sections: insight → proof → CTA |
| Website copy (service page) | Hero headline ≤10 words; 3–5 value props; 1 CTA per section |

Every asset must map to one of these pillars:
| Pillar | Core message |
|---|---|
| AI That Has a Foundation | AI is only as good as the data underneath it. Teqfocus builds both. |
| Full-Stack Partnership | From raw data to intelligent application — one partner, no gaps |

### Quality test — run on every draft
> "Could this content appear on a competitor's site without changing a word?"
> If YES → rewrite. If NO → it passes.

## Section 9: Content Refresh vs. Rewrite Decision Matrix

Before spending time rewriting old content, decide the right intervention:

| Situation | Action |
|---|---|
| Traffic declining but intent still valid | Refresh: update stats, add new examples, improve SEO |
| Stats/data are stale (>18 months) | Refresh: update specific claims |
| Product or service has changed | Rewrite: the premise has shifted |
| Keyword cannibalization discovered | Consolidate: merge into stronger page |
| Engagement low, bounce rate high | Rewrite: message-audience fit is wrong |
| Page ranks but doesn't convert | CRO: messaging/CTA problem, not content problem |
| Topic completely outdated (e.g., pre-AI) | Archive or redirect: not worth updating |

**Refresh triggers (check quarterly):**
- Any statistic from before the current year
- Platform references (check if still current — Pardot → Marketing Cloud Account Engagement)
- Client case studies (confirm client still active and approved)
- Pricing references (if publicly mentioned)

## Section 10: Emotional and Risk Reduction in Copy

Two sweeps that are consistently missing from Teqfocus copy:

### Emotional Resonance Sweep
Every asset should make the reader feel something specific.
For Teqfocus's CIO/CDO buyers, the right emotions are:

- **Confidence:** "This will actually work" — backed by specific proof
- **Relief:** "Someone finally understands this problem"
- **Urgency:** "I can't keep ignoring this" — not manufactured, real stakes

Test: After reading this copy, does the buyer feel differently than before?
If no — it's informational, not persuasive. Add one of:
- A consequence that resonates ("Every month without unified data...")
- A peer reference ("Other healthcare CDOs we work with describe it as...")
- A future state image ("Imagine your sales team..."

### Risk Reduction Sweep
Enterprise buyers weight risk heavily. For every claim in copy, ask:
"What's the buyer's fear about this claim?" Then address it.

| Claim | Fear | Risk reduction copy |
|---|---|---|
| "We'll deliver in 90 days" | "They'll rush and cut corners" | "Fixed-scope with defined milestones and weekly reviews" |
| "We've done this for healthcare orgs" | "They'll use generic approaches" | "We've mapped to your specific payer/provider workflows" |
| "Starting at $50K" | "It'll balloon to $500K" | "Phase 1 is fixed-scope. You decide before we proceed to Phase 2." |

## Section 11: 2026 Content Format Data + TeqTalk Splintering Hierarchy

### 2026 LinkedIn Format Performance (Source: Oktopost B2B Benchmark, March 2026, n=1,000+)
| Format | Engagement rate | Priority for Teqfocus |
|---|---|---|
| Document carousel (PDF post) | 6.60% | #1 — weekly |
| Native video (60–90s) | 5.60% | #2 — weekly |
| Text post (1,300–3,000 chars) | 2.90% | #3 — weekly |
| External link post | ~1.5% (penalized -60%) | Avoid in post body |

**Dwell time is the primary 2026 algorithm signal.**
Every content decision should ask: will this make someone pause and read for 60+ seconds?
- Carousels win because each swipe extends dwell time
- Long-form text wins because it takes 30–60 seconds to read
- Short posts with links lose because they generate one click and a fast scroll-past
