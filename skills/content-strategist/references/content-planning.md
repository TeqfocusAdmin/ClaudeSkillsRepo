## Quarterly Content Calendar Framework

**Q1 (Jan–Mar):** Pipeline generation — decision-stage content to close Q1 deals
- Case studies, ROI narratives, competitive comparisons
- TeqTalk: CDO/CIO guests on outcomes they've achieved

**Q2 (Apr–Jun):** Awareness and event season (Dreamforce prep)
- Thought leadership ahead of Dreamforce
- Industry vertical content: healthcare AI, finserv digital
- Event-themed content: what to expect at Dreamforce, Snowflake Summit

**Q3 (Jul–Sep):** Dreamforce and Snowflake Summit activation
- Event content, co-marketing with Salesforce/Snowflake
- Post-event follow-up content for attendees

**Q4 (Oct–Dec):** Planning season — target CDOs/CIOs setting next-year roadmaps
- White papers: "AI Readiness Assessment for 2025/2026"
- Planning-focused content: "How to build your data transformation roadmap"
- Year-end case studies and proof

## Content Audit Framework

Before creating new content, audit what exists:
1. Does a page or post already cover this topic?
2. Is it current (< 12 months for fast-moving topics)?
3. Does it rank for the target keyword?
4. Does it convert? (check GA4 if available)

Decision tree:
- Exists + current + ranks + converts → Promote it, don't recreate
- Exists + current + doesn't rank → Optimize for SEO, build links
- Exists + outdated → Refresh (use copy-editing reference)
- Doesn't exist → Create (use relevant asset reference)
