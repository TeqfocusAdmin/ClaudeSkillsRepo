# Teqfocus Pinned Comment

The pinned comment is the post's second act. It carries the link (protecting post reach), extends the argument, or asks the question that starts the thread. Every Teqfocus post that links out gets one.

**Prerequisite:** Read `/mnt/skills/user/teqfocus-gtm/SKILL.md` first.

## Three pinned-comment types — pick by post goal

### 1. Link carrier (post drives to a resource)
2–3 lines: restate the payoff of clicking in the reader's terms, then the link. Never "link below 👇" energy — the comment earns the click on its own.
> "The full architecture pattern — including the four compliance pillars most teams miss — is in the vertical guide: [link]"

### 2. Extension (post made a claim; comment adds the layer that didn't fit)
The detail, caveat, or counter-consideration that makes commenters say "this is the real insight." 3–5 lines. This is where nuance lives that would have killed the post's punch.

### 3. Discussion seed (post ends on a question)
One sharpened follow-up that lowers the barrier to replying — offer two sides to pick from, or a specific scenario to react to. Senior-practitioner tone; never engagement-bait ("comment YES if...").

## Voice rules

- Same voice as the posting profile (company page vs. Avi vs. Jas) — the comment must not read like a different author
- Banned words and openers apply
- Humor allowed on personal profiles, dry and specific — never meme-format on the company page; if the user wants a meme-style pin for a personal profile, keep it text-only or route the image to teqfocus-infographic (whiteboard path)
- One link maximum. No hashtag stuffing in comments.
- Metrics referenced get `[VERIFY]` unless already verified in the post

## Timing note (include with every delivery)

Pin within 2 minutes of posting. If the post uses a link carrier, the author's next action is replying to the first 3 organic comments within the first hour — note this in the delivery.

## Output

The pinned comment ready to paste, type labeled, plus one alternate. If the parent post doesn't exist yet, route post production to linkedin-campaigns first — this skill never writes the post itself.
