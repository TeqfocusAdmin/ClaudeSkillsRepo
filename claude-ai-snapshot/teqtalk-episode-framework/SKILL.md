# Skill: teqtalk-episode-framework
## Stage 1 — Pre-Production | Episode Architecture

Read: `framework/BRAND_VOICE.md` · `framework/AUDIENCE_INTEL.md` · Guest brief for this episode

---

## What This Skill Produces

The 3–4 questions that give the episode its spine. Not a list of everything to ask — the specific questions that will produce the moments worth repurposing. These are the questions that separate a great episode from a competent one.

---

## Input Required

```
GUEST BRIEF: [Paste completed guest brief]
EPISODE DURATION TARGET: [30 / 45 / 60 minutes]
PRIMARY AUDIENCE: [CIO / CDO / CTO / Transformation Exec / Healthcare CXO]
EPISODE THEME: [The specific angle for this guest]
```

---

## The 4-Iteration Loop

### Pass 1 — Draft Framework
Build 4 candidate questions. Each must: create a narrative tension, invite a specific story (not a general answer), and connect to a decision the target audience is currently navigating.

### Pass 2 — Arc Test
Do these 4 questions tell a complete story with a beginning (the problem), middle (the decision and its consequences), and end (the insight or lesson)? If not, restructure.

### Pass 3 — Wow Moment Check
Is there one question in the set that no other podcast would ask this guest? One that requires a genuine, unrehearsed answer? If not, replace the safest question with the sharpest provocation from the guest brief.

### Pass 4 — Audience Value Confirmation
For each question: "What specific, actionable insight would a CDO or CIO take away from a great answer to this question?" If the answer is vague — rewrite the question.

## Quality Test

"Could these 4 questions be asked of any guest in this field?" If yes — they are too generic. Every question should only work for this specific guest.
