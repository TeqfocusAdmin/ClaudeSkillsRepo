# Teqfocus Hook Generator

The first two lines decide whether the next 200 get read. This skill produces 6 hook variations per topic, each from a different mechanism, so the writer picks the strongest opening before drafting the body.

**Prerequisite:** Read `/mnt/skills/user/teqfocus-gtm/SKILL.md` first for persona and voice context.

## The 6 mechanisms — one hook each, every time

1. **Contrarian** — challenge the accepted playbook. "Most Salesforce implementations fail before the first login. The data underneath was never fixed."
2. **Specific stat** — a number that reframes the problem. Must be real; flag `[VERIFY]` if unsourced. Never invent.
3. **Buyer's inner monologue** — the sentence the CIO says to themselves but not in meetings. "Your CRM is clean. Your forecast is still a guess."
4. **Story cold-open** — drop into the middle of a real moment. "The CFO asked one question in the QBR. Nobody in the room could answer it."
5. **Cost of inaction** — what staying still is quietly costing. "Every quarter without governed data is another quarter of AI projects that can't ship."
6. **Pattern interrupt** — an unexpected comparison or format break that still lands on the business problem within line two.

## Rules

- Two lines max per hook. Line 1 stops the scroll; line 2 makes skipping feel expensive.
- Each hook must name or clearly imply the target persona's world (CIO / CDO / RevOps / VP Sales) — no generic "leaders" hooks.
- Banned openers apply: never start with "Excited to share", "Proud to announce", "I", or "We".
- Banned words apply: leverage, synergy, holistic, best-in-class, cutting-edge, robust, end-to-end solutions.
- Clickbait energy, senior-practitioner substance. Every hook must be a promise the body can actually keep.
- No em-dash-heavy AI cadence — run hooks through humanizer patterns mentally before presenting.

## Output format

Numbered 1–6, mechanism labeled, then a one-line recommendation: which hook fits this topic + persona + channel and why. If the user is writing a reel, note which hooks survive being spoken aloud (stat and monologue usually do; pattern interrupts often don't).

## Handoff

Chosen hook routes with the topic to the producing skill: linkedin-campaigns for posts, teqtalk-reel-extractor for reels, content-strategist for newsletters and blogs.
