# Reference: Copy Editing — Teqfocus

Use when existing Teqfocus copy needs review, improvement, or refresh.
This is an editing pass — not a rewrite from scratch.
For new copy, use the relevant asset reference file first, then edit here.

---

## The 7-Sweep Editing Process

Run these sweeps in order. Each fixes one class of problem.

### Sweep 1: Clarity
Does every sentence say exactly one thing clearly?
- Remove hedge words: "quite," "rather," "somewhat," "very," "really"
- Remove qualifiers: "almost," "nearly," "arguably"
- Replace jargon with plain language: "leverage" → "use," "utilize" → "use"
- Break sentences over 25 words into two

### Sweep 2: Specificity
Is every claim specific enough to be credible?
- Replace vague claims with specific ones:
  ❌ "Teqfocus is highly experienced"
  ✅ "400+ Salesforce certifications, 4.9 CSAT, partner since 2012"
- Replace "enterprise clients" with actual industry if possible
- Replace "significant improvement" with a number (or flag [VERIFY])

### Sweep 3: Buyer Language
Does the copy sound like the buyer, not Teqfocus?
- Replace internal terms with buyer terms:
  ❌ "Full Lifecycle Engagement"
  ✅ "From architecture to go-live — and support after"
- Mirror language from customer-research skill if available
- Check: "Would a CIO say this in a meeting?" If no — rewrite it.

### Sweep 4: Outcomes Over Features
Is every capability connected to a business result?
- Run "which means..." test on every feature/service statement
  "We implement Health Cloud" → "which means..." → 
  "your care teams work from a single patient record, not 4 systems"
- Remove standalone platform lists with no outcome attached

### Sweep 5: Voice Compliance
Does the copy follow Teqfocus voice rules?
Check against teqfocus-gtm banned words:
- Never use: leverage · synergy · holistic · best-in-class · cutting-edge ·
  robust · end-to-end solutions
- Never open with: "Excited to share" · "Proud to announce" · "We" · "I"
- Salesforce Summit credential: present once, naturally — never as news

### Sweep 6: CTA and Structure
- Is there exactly one CTA per asset? Remove competing actions.
- Is the CTA specific? "Book a 30-minute data readiness review" not "Contact us"
- Is the most important information first? (inverted pyramid for most formats)
- Does the headline/subject line pass the 5-second test?

### Sweep 7: American English and Brand
- American English throughout: personalize, organize, color, behavior, center
- No British variants: personalise, organise, colour, behaviour, centre
- Teqfocus spelled correctly — never TeqFocus, TEQFOCUS, Teq Focus
- No invented metrics — any unverified number flagged with [VERIFY]

## Content Refresh Checklist

Use when existing page copy is more than 12 months old:

- [ ] Are all statistics current? (industry stats, Teqfocus credentials)
- [ ] Does the platform stack reflect current Teqfocus capabilities?
- [ ] Is the case study/proof still the best available match for this page?
- [ ] Has the buyer's language evolved? (new terms: Agentforce vs Einstein Bot)
- [ ] Does the CTA match the current campaign or offer?
- [ ] Are any deprecated products or services mentioned?

## Quick Reference: Strong vs Weak Copy Patterns

| Weak | Strong |
|---|---|
| "We help enterprises transform" | "Healthcare payers cut prior auth cycles from 14 to 2 days" [VERIFY] |
| "Cutting-edge Salesforce solutions" | "Salesforce built to perform — not just go live" |
| "We are a Summit Partner" | "Summit-tier depth on every engagement" |
| "Let's connect" | "Book a 30-minute data readiness review" |
| "Leverage our expertise" | "Work with a team that's done this 400+ times" |
| "Holistic transformation" | "Data, AI, and Salesforce — connected from day one" |
