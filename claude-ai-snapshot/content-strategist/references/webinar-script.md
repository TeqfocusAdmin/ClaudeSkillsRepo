# Reference: Webinar Script / Speaker Notes

Length: 45-min session ≈ 5,500 words | 60-min ≈ 7,500 words
Format: Speaker notes document (.docx) with slide cues marked

## Script Structure

### Opening (3–5 minutes)
```
[SLIDE CUE: Title slide]
"Welcome everyone — [Host name] here from Teqfocus.
Today we're going to cover [specific outcome the attendee will leave with].
If you're [persona description] dealing with [specific pain], this session
is built for you.
Quick housekeeping: [recording/Q&A note].
Let's get into it."
```

### Problem Frame (5–8 minutes)
```
[SLIDE CUE: Problem/context slide]
- Open with an industry statistic or recent shift (cited, verified)
- State the problem the audience is living with right now
- Validate the frustration: "Most teams we talk to describe it this way..."
- Raise the stakes: what happens if this isn't solved?
```

### Core Content (20–30 minutes)
- Break into 3 sections, each with a [SLIDE CUE]
- Each section: insight (2 min) → example (3 min) → key takeaway (1 min)
- Use transition phrases: "So if that's the problem, here's what we've seen work..."
- Pause for questions mid-way: "Before I move on — any questions on [topic]?"

### Demo or Case Study Walkthrough (8–12 minutes)
```
[SLIDE CUE: Case study / demo slide]
"Let me walk you through a real example.
[Company type, not always named] came to us with [specific problem].
Here's what we found, what we built, and what changed for their business."
Challenge → Solution → Outcome — same structure as case study
```

### Wrap-Up and CTA (5 minutes)
```
[SLIDE CUE: Next steps slide]
"Three things to take away from today:
1. [Key insight 1]
2. [Key insight 2]
3. [Key insight 3]

If you want to explore what this looks like for your specific situation,
[CTA — book a session, download resource, etc.]

We'll stay on for questions."
```

### Q&A Notes
- Prepare 5 anticipated questions with answers
- Flag sensitive topics (pricing, competitors) with redirect language
- Close: "Thanks everyone — [host name] from Teqfocus. See you next time."

## Production Notes
- Write in natural spoken English — not formal prose
- Short sentences — easy to read at speed
- Mark every slide transition with [SLIDE CUE: description]
- Time markers every 5 minutes: [~15 MIN MARK]
- Flag ad-lib areas with [PAUSE — CHECK CHAT]
